# Logo nền tảng

Các asset trong `public/brand/social/` lấy từ nguồn chính thức, lưu local để widget không phụ thuộc request bên thứ ba. Không vẽ lại logo bằng icon chung.

| Nền tảng  | File          | Nguồn                                                                                                                     |
| --------- | ------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Facebook  | facebook.png  | [Meta — Facebook logo](https://www.meta.com/brand/resources/facebook/logo/), Primary Logo trong Facebook Brand Asset Pack |
| Messenger | messenger.svg | [Meta — Messenger icon](https://www.meta.com/brand/resources/facebook/messenger-icon/), Primary Blue                      |
| Instagram | instagram.svg | [Meta — Instagram](https://www.meta.com/brand/resources/instagram/instagram-brand/), White Glyph trên nền màu             |
| Zalo      | zalo.webp     | [Zalo](https://zalo.me/vi/), logo trong header                                                                            |
| TikTok    | tiktok.ico    | [TikTok](https://www.tiktok.com/favicon.ico), favicon chính thức                                                          |
| YouTube   | youtube.png   | [YouTube](https://www.youtube.com/), favicon chính thức 144 px                                                            |

Logo nền tảng mặc định giữ tỷ lệ và hiển thị đầy đủ. Admin có thể tải logo riêng hoặc chọn ảnh từ thư viện trong Thiết lập → Widget liên hệ nổi → Chỉnh logo. Gỡ ảnh để quay lại logo chính thức. Hình tùy chỉnh chỉ thay vùng hiển thị, giữ file gốc.
